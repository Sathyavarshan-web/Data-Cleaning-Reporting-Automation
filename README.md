# Data-Cleaning-Reporting-Automation

## Project Overview
This project automates the process of cleaning raw sales data and generating reports using Python.

## Features
- Removes duplicate records
- Handles missing values
- Standardizes text formatting
- Converts date formats
- Generates visualizations
- Creates Excel and PDF reports

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- OpenPyXL
- ReportLab
- Google Colab

## Project Workflow
1. Load raw data
2. Explore the dataset
3. Clean the data
4. Generate charts
5. Create Excel report
6. Generate PDF report

## Output Files
- cleaned_sales_data.csv
- summary_report.xlsx
- Data_Cleaning_Report.pdf
- sales_by_product.png
- sales_by_city.png
- product_distribution.png
